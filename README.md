# 🚀 SpaceX Fleet Performance & Starlink Analytics Dashboard

A dark-themed, pixel-perfect 2-page Power BI dashboard built to analyze SpaceX launch dynamics, fleet reusability, and Starlink satellite constellation health.

---

## 🌟 Overview & Key Pages

### 1. Fleet Performance (Overview)
* **KPI Metrics:** Total launches, overall success rate (88.29%), rocket reuse rate (57.07%), and active rocket model counts.
* **Launch Dynamics (YoY):** Line chart showcasing launch velocity trends over time.
* **Launchpad & Rocket Breakdown:** Bar charts analyzing mission volume by launch site and success rates per rocket type.

### 2. Starlink Analytics (Details Page)
* **Constellation Health:** Tracking total vs. active satellites alongside operational share (92.68%).
* **Global Satellite Map:** Geographical visualization of live orbital coverage across latitude/longitude bounds.
* **Orbital Profile:** Altitude distribution ($300\text{--}600\text{ km}$) and inclination breakdown for active satellites.

---

## 🎨 UI/UX & Technical Features

* **Native Container Design:** Built using native Power BI containers with rounded borders ($10\text{--}12\text{ px}$) and neon glowing outlines (`#38BDF8`) for a modern Sci-Fi aesthetic.
* **Modular Layout:** Fully responsive visual alignment engineered without static image backgrounds.
* **Interactive Navigation:** Seamless page transitions using custom-styled navigation buttons.
